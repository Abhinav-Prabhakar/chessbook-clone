# Bundled piece sets

Mirror of `/pieces` for the Vite build. See `pieces/README.md` at the repository
root for attribution and licence details.

Sets: `chessbook_monochrome` (default/fallback), `cburnett` (GPLv2+),
`merida` (GPLv2+), `chessnut` (Apache 2.0), `shapes` (CC BY-SA 4.0).

Each folder contains `wK wQ wR wB wN wP bK bQ bR bB bN bP` as SVG.
Downloaded from `https://lichess1.org/assets/piece/<set>/<piece>.svg`.
